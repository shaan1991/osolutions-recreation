What was built

Every page opens like a script: a prompt, a command, and output. Visitors type real commands or tap preset ones, and the terminal carries them to the page they asked for. The home page boots like a system. The portfolio reads like a directory listing. The estimator runs like an installer with six questions.

Content lives in code and renders statically. There is no CMS, no plugins, and nothing to lock a client in. The single accent color keeps the whole site coherent from the first boot line to the contact script.
